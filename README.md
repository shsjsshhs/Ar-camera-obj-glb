# Ar-camera-obj-glb 🇧🇷 Português
Visor AR — site que transforma a câmera do celular num visor de realidade aumentada simples: você importa um objeto 3D (.obj ou .glb), ele aparece sobreposto à imagem da câmera ao vivo, e dá pra mover, girar e escalar com toque. Um botão de travamento usa o giroscópio do aparelho pra fixar o objeto num ponto do espaço real — ele some e reaparece conforme você vira a câmera, como se fosse algo realmente ali. Também grava a cena composta (câmera + objeto) em vídeo, direto em MP4 quando o navegador suporta, ou WebM como alternativa.
Recursos
Câmera ao vivo em tela cheia, com troca entre frontal/traseira
Importação de modelos .obj e .glb (com animações do .glb, se houver)
Mover (arrastar), girar e escalar por toque, pinça ou botões
Travamento espacial via sensor de movimento (giroscópio) — o objeto fica ancorado no ambiente, não na tela
Gravação em vídeo (MP4 ou WebM, conforme suporte do navegador) da cena com o objeto sobreposto
Créditos
Construído com Claude (Anthropic), usando Three.js para renderização 3D.
🇺🇸 English
AR Viewer — a website that turns your phone's camera into a simple augmented-reality viewer: import a 3D object (.obj or .glb), see it overlaid on the live camera feed, and move, rotate, and scale it with touch. A lock button uses the device's gyroscope to anchor the object to a point in real space — it disappears and reappears as you turn the camera, as if it were really standing there. It also records the composited scene (camera + object) to video, straight to MP4 when the browser supports it, falling back to WebM otherwise.
Features
Full-screen live camera with front/back switching
Import .obj and .glb models (plays .glb embedded animations)
Move (drag), rotate, and scale via touch, pinch, or buttons
Spatial lock via the device's motion sensor (gyroscope) — the object anchors to the environment, not the screen
Video recording (MP4 or WebM, depending on browser support) of the scene with the overlaid object
Credits
Built with Claude (Anthropic), using Three.js for 3D rendering.
